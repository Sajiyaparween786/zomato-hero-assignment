# 🍽️ Zomato Clone

A frontend clone of the Zomato website built as part of my 💻 Web Development Internship assignment. This project focuses on recreating the layout and visual design of the Zomato landing page using HTML and CSS while practicing modern frontend development concepts.

## 📌 Project Overview

The webpage contains multiple sections inspired by the Zomato website, including a 🎥 hero section, 🃏 content cards, 📱 app download section, and 🔗 footer. The main goal of this project was to understand how real-world websites are structured and styled.

## 📚 What I Learned

Through this project, I practiced:

* 🏗️ HTML page structuring
* 🎨 CSS styling and layout design
* 📍 Positioning elements using different CSS properties
* 📦 Flexbox for alignment and spacing
* 🖼️ Working with images, icons, and video backgrounds
* 🧹 Creating reusable and organized CSS
* 🌐 Designing sections similar to a production website
* ✨ Basic scroll-based animation effects

## 🚀 Features

* 🍴 Multi-section Zomato-inspired landing page
* 🎥 Video background hero section
* 📱 App download section
* 🖱️ Hover effects on interactive elements
* ✨ Scroll animation in the final section
* 🧾 Clean and organized code structure

## 🛠️ Technologies Used

* 🌐 HTML5
* 🎨 CSS3
